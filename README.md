# המשימות שלי

מערכת משימות אישית: קטגוריות ותת־קטגוריות, משימות חוזרות, רשימת עדיפויות, תיבת "ממתין לרב סגל", משימות המשך, תיעוד לפי תאריך ושעות עבודה.

- האתר: `index.html` (GitHub Pages)
- השרת: `apps-script/Code.gs` (Google Apps Script שמחובר לגיליון "משימות שלי - נתונים")

כל עוד לא הוגדרה כתובת שרת, האתר עובד ב**מצב מקומי**: הנתונים נשמרים רק בדפדפן. זה טוב לניסיון.

## התקנה (פעם אחת)

### 1. הדבקת קוד השרת
1. פותחים את הגיליון **משימות שלי - נתונים** ב-Google Drive.
2. בתפריט: **תוספים ← Apps Script**.
3. מוחקים את מה שיש בקובץ `Code.gs` ומדביקים את כל התוכן של [`apps-script/Code.gs`](apps-script/Code.gs). שומרים (💾).

### 2. הגדרת קוד העריכה
1. בעורך ה-Apps Script: **⚙️ הגדרות הפרויקט** (בתפריט הצד).
2. למטה, **מאפייני סקריפט ← הוספת מאפיין**.
3. מאפיין: `EDIT_CODE`. ערך: הקוד שתרצה. שומרים.

> הקוד לא כתוב בשום קובץ במאגר, כי המאגר ציבורי.

### 3. פריסה
1. **פריסה ← פריסה חדשה**, ובגלגל השיניים בוחרים **אפליקציית אינטרנט**.
2. **הפעלה בתור:** אני. **למי יש גישה:** כל אחד.
3. **פריסה**. בפעם הראשונה Google תבקש לאשר הרשאות: מאשרים (מתקדם ← מעבר לפרויקט).
4. מעתיקים את **כתובת אפליקציית האינטרנט**. היא מסתיימת ב-`/exec`.

### 4. חיבור האתר
- באתר: **⚙️ ← כתובת Apps Script**. מדביקים את הכתובת ולוחצים "שמור כתובת".
- אחר כך לוחצים **🔒 כניסה** ומזינים את קוד העריכה.
- כדי שהכתובת תעבוד אצל כל מי שנכנס (גם בלי הגדרה), שולחים אותה ל-Claude, והוא יכניס אותה ל-`DEFAULT_GAS_URL` ב-`index.html`.

### עדכון קוד השרת בעתיד
אחרי הדבקת קוד חדש: **פריסה ← ניהול פריסות ← ✎ ← גרסה: גרסה חדשה ← פריסה**. הכתובת נשארת אותה כתובת.
